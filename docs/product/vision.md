# Product vision

**Mission:** create a customizable open-source desk companion that feels alive and helps developers organize and understand their projects.

## Key user experiences
- Ambient, nonintrusive expressions and behaviors with no LLM dependency.
- Project Kanban, user stories, repository and documentation access.
- Contextual code Q&A using a self-hosted Ollama service.
- Virtual-first: browser simulator works without any 3D-printed hardware.
- Fully customizable bodies, drivers and modules with explicit capabilities.

## MVP boundaries
In: repo foundation, simulated companion, read-only project data, contextual Q&A.
Out: motorized body, speech, unrestricted code execution, auto-writing to repositories, plugin marketplace.

## Audiences
Personal developer first; later maintainers, makers and community contributors.
